# Welcome to md-e2e

**md-e2e** is a Zero-Glue-Code, Markdown-Based E2E Test Automation Framework powered by Playwright.

It bridges the gap between technical and non-technical stakeholders by executing human-readable specifications written in Markdown directly as E2E browser tests.

---

## Key Features

- **Markdown-Native specifications**: Write scenarios as lists, tables, and setup blocks.
- **Accessibility-First Locators**: Auto-resolves targets based on ARIA roles, labels, and text.
- **Self-Healing Engine**: Captures timeouts and dynamically resolves selectors using offline fuzzy heuristics and optional AI fallback.
- **Rich Dashboard Reporting**: Produces clean Markdown summary reports and zero-dependency interactive HTML dashboards.
- **Standalone CLI & Step Debugger**: Fast scaffolding, headed/headless runs, and interactive stepping with element highlighting.
- **Pytest Plugin**: Direct integration with your existing Python test infrastructure.
